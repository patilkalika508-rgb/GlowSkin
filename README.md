GlowSkin
A skincare e-commerce website built using HTML, CSS, JavaScript and Node.js with Express.

🌿 GlowSkin – Skincare E-Commerce Website

GlowSkin is a skincare e-commerce website designed to provide users with a simple and smooth online shopping experience. It features a clean, elegant interface where users can explore skincare products, add items to their cart and proceed to checkout.

✨ Features

- **Home Page:** Attractive landing page with a skincare-themed design.
- **Product Catalog:** Browse different skincare products.
- **Search Functionality:** Search for products easily.
- **Category Filters:** Filter products based on categories.
- **Product Details:** View product information and prices.
- **Shopping Cart:** Add, remove and update product quantities.
- **Order Summary:** View subtotal and total amount.
- **Checkout Page:** Enter delivery details and place a demo order.
- **Responsive Design:** Clean and user-friendly interface.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- LocalStorage

🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install the required dependencies:

```bash
npm install
```

5. Start the server:

```bash
node server.js
```

6. Open your browser and visit:

```text
http://localhost:8000
```
